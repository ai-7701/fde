What is encoding and when to use it?

Machine-learning workflows often need categorical text values converted into numeric form. Choose the method based on the question and the meaning of the category.

MethodWhen to useTypical output
Label EncodingMap each category to an integer; use when explicitly requested or for suitable ordinal categories.Department → 0, 1, 2
One-Hot EncodingCreate a separate binary column for each category; useful for nominal categories.City_Chennai, City_Delhi…
Label Encoding creates numeric labels, but those numbers do not automatically mean one department is greater than another. For nominal categories, One-Hot Encoding often avoids implying an order.

Handle missing values and duplicates

Clean the data before encoding. This version fills numeric columns with median and text columns with mode, then removes duplicate rows.

PYTHON · CLEANING
# Identify missing values
print(df.isnull().sum())

# Fill numerical columns
for col in df.select_dtypes(include="number").columns:
    df[col] = df[col].fillna(df[col].median())

# Fill categorical columns
for col in df.select_dtypes(include="object").columns:
    if df[col].notna().any() and not df[col].mode().empty:
        df[col] = df[col].fillna(df[col].mode()[0])

# Identify and remove duplicates
print("Duplicates:", df.duplicated().sum())
df.drop_duplicates(inplace=True)

print(df.isnull().sum())

Label Encoding — Department

le = LabelEncoder()

df["Department"] = le.fit_transform(df["Department"])

print(df[["Department"]].head())

for category, number in zip(le.classes_, le.transform(le.classes_)):

Complete Set A-style 15-mark program

Full reusable answer for missing values, duplicate removal, Label Encoding of Department, One-Hot Encoding of City and CSV export.

PYTHON · COMPLETE TEMPLATE
import pandas as pd
from sklearn.preprocessing import LabelEncoder

df = pd.read_csv("employee_A.csv")

# 1. Identify and handle missing values
print(df.isnull().sum())

for col in df.select_dtypes(include="number").columns:
    df[col] = df[col].fillna(df[col].median())

for col in df.select_dtypes(include="object").columns:
    if df[col].notna().any() and not df[col].mode().empty:
        df[col] = df[col].fillna(df[col].mode()[0])

# 2. Identify and remove duplicates
print("Duplicates:", df.duplicated().sum())
df.drop_duplicates(inplace=True)

# 3. Label Encoding
le = LabelEncoder()
df["Department"] = le.fit_transform(df["Department"])

# 4. One-Hot Encoding
df = pd.get_dummies(df, columns=["City"], dtype=int)

# 5. Save cleaned dataset
df.to_csv("employee_A_cleaned.csv", index=False)

print(df.head())
print("Saved successfully!")
If the question changes the column names, replace Department and City. If it asks for only one encoding operation, omit the other one.
