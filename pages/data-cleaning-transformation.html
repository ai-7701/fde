Missing values — identify and handle

isnull().sum() counts missing values in each column. A common general strategy is median for numeric columns and mode for categorical columns. Follow the question's instruction if it specifies a different method.

PYTHON · GENERAL IMPUTATION
print("Missing values before:")
print(df.isnull().sum())

# Fill numerical columns with their median
for col in df.select_dtypes(include="number").columns:
    df[col] = df[col].fillna(df[col].median())

# Fill categorical columns with their mode
for col in df.select_dtypes(include=["object", "category"]).columns:
    if df[col].notna().any() and not df[col].mode().empty:
        df[col] = df[col].fillna(df[col].mode()[0])

print("Missing values after:")
print(df.isnull().sum())

Other common choices

  • df.dropna() — remove rows containing missing values.
  • df["Age"].fillna(df["Age"].mean()) — fill a numeric column with its mean.
  • df["City"].fillna(df["City"].mode()[0]) — fill a categorical column with its most frequent value.
  • df["Column"].fillna(0) — replace missing values with zero when appropriate.

Min-Max Normalization

Use when the question specifically asks for Min-Max normalization. It rescales numeric values to a chosen range; the default range is 0 to 1.

Xscaled = (X − Xmin) / (Xmax − Xmin)
PYTHON · MIN-MAX SCALING
scaler = MinMaxScaler()

df[["Unit_Price"]] = scaler.fit_transform(df[["Unit_Price"]])

print(df[["Unit_Price"]].head())
Keep the double brackets: df[["Unit_Price"]] gives Scikit-learn a 2D DataFrame. Change the column name to the one specified in the question.

Standardization (Z-score)

Use when the question asks for standardization or Z-score scaling. It transforms values based on the column mean and standard deviation.

Z = (X − μ) / σ

μ = mean; σ = standard deviation. After standardization, the transformed column has mean approximately 0 and standard deviation approximately 1.

PYTHON · STANDARD SCALING
scaler = StandardScaler()

df[["Quantity"]] = scaler.fit_transform(df[["Quantity"]])

print(df[["Quantity"]].head())

Complete Set B-style 15-mark program

This combined program follows the Set B order: inspect → handle missing values → remove duplicates → calculate Total_Amount → normalize Unit_Price → standardize Quantity → export.

PYTHON · COMPLETE TEMPLATE
import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler, StandardScaler

df = pd.read_csv("sales_B.csv")

# 1. Identify and handle missing values
print(df.isnull().sum())

for col in df.select_dtypes(include="number").columns:
    df[col] = df[col].fillna(df[col].median())

for col in df.select_dtypes(include=["object", "category"]).columns:
    if df[col].notna().any() and not df[col].mode().empty:
        df[col] = df[col].fillna(df[col].mode()[0])

# 2. Identify and remove duplicates
print("Duplicates:", df.duplicated().sum())
df.drop_duplicates(inplace=True)

# 3. Create a calculated column
df["Total_Amount"] = df["Quantity"] * df["Unit_Price"]

# 4. Min-Max normalize Unit_Price
minmax = MinMaxScaler()
df[["Unit_Price"]] = minmax.fit_transform(df[["Unit_Price"]])

# 5. Standardize Quantity
standard = StandardScaler()
df[["Quantity"]] = standard.fit_transform(df[["Quantity"]])

# 6. Save transformed dataset
df.to_csv("sales_B_transformed.csv", index=False)

print(df.head())
print("Saved successfully!")
This assumes the CSV contains columns named Quantity and Unit_Price. Check the actual column names first. Imputation should happen before scaling.
