A. API extraction — TMDB movies

Use when: the question gives an API URL and API key. Your API notebook calls the TMDB top-rated movies endpoint, reads the JSON response, selects the results list and extracts four columns.

Master code — one API page

PYTHON · ONE PAGE
import requests
import pandas as pd

api_key = "PASTE_YOUR_OWN_API_KEY"
url = "https://api.themoviedb.org/3/movie/top_rated"

params = {
    "api_key": api_key,
    "language": "en-US",
    "page": 1
}

response = requests.get(url, params=params, timeout=20)
response.raise_for_status()

data = response.json()
print(data.keys())

df = pd.DataFrame(data["results"])[
    ["title", "original_language", "overview", "popularity"]
]

print(df.head())
df.to_csv("movies.csv", index=False)

Master code — multiple pages

Your notebook loops through pages and appends each page's DataFrame to a list, then combines them with pd.concat(). This is the reusable version; it uses the API's total_pages response rather than hard-coding a page count.

PYTHON · PAGINATED API
import requests
import pandas as pd

api_key = "PASTE_YOUR_OWN_API_KEY"
url = "https://api.themoviedb.org/3/movie/top_rated"

all_rows = []
page = 1
total_pages = 1

while page <= total_pages:
    params = {
        "api_key": api_key,
        "language": "en-US",
        "page": page
    }

    response = requests.get(url, params=params, timeout=20)
    response.raise_for_status()
    data = response.json()

    total_pages = min(data.get("total_pages", 1), 500)

    for movie in data.get("results", []):
        all_rows.append({
            "title": movie.get("title"),
            "original_language": movie.get("original_language"),
            "overview": movie.get("overview"),
            "popularity": movie.get("popularity")
        })

    page += 1

df = pd.DataFrame(all_rows)
print(df.head())
print("Total records:", len(df))
df.to_csv("tmdb_movies.csv", index=False)
The notebook's key pattern is response.json()['results'], then selecting columns from that list. pd.concat(list_of_dataframes, ignore_index=True) combines page-wise DataFrames.
The uploaded API notebook contains a hard-coded API credential. Do not reuse or publish that credential. Regenerate/revoke it in the provider account and use your own key privately. Never put a real key in a public GitHub repository.

B. Books website — static HTML + pagination

Use when: a question provides a normal website URL and asks for book details. Your notebook extracts title, price, rating and stock/availability from each article.product_pod and iterates through catalogue pages.

Single-page pattern

PYTHON · ONE PAGE
import pandas as pd
import requests
from bs4 import BeautifulSoup

url = "https://books.toscrape.com/"
webpage = requests.get(url, timeout=20).text
soup = BeautifulSoup(webpage, "lxml")

books = soup.find_all("article", class_="product_pod")
data = []

for book in books:
    title = book.h3.a["title"]
    price = book.find("p", class_="price_color").get_text(strip=True)
    rating = book.find("p", class_="star-rating")["class"][1]
    stock = book.find("p", class_="instock availability").get_text(strip=True)

    data.append({
        "Title": title,
        "Price": price,
        "Rating": rating,
        "Stock": stock
    })

df = pd.DataFrame(data)
print(df.head())

Multi-page pattern — matching your notebook

PYTHON · 50 CATALOGUE PAGES
import pandas as pd
import requests
from bs4 import BeautifulSoup
import time

base_url = "https://books.toscrape.com/catalogue/page-{}.html"
all_books = []

for page in range(1, 51):
    url = base_url.format(page)
    response = requests.get(url, timeout=20)
    response.raise_for_status()

    print("Scraping page:", page)
    soup = BeautifulSoup(response.text, "html.parser")
    books = soup.find_all("article", class_="product_pod")

    for book in books:
        title = book.h3.a["title"]
        price = book.find("p", class_="price_color").get_text(strip=True)
        rating = book.find("p", class_="star-rating")["class"][1]
        availability = book.find(
            "p", class_="instock availability"
        ).get_text(strip=True)

        all_books.append({
            "Title": title,
            "Price": price,
            "Rating": rating,
            "Availability": availability
        })

    time.sleep(0.2)  # small delay between page requests

df = pd.DataFrame(all_books)
print("Total records:", len(df))
print(df.head())

df.to_csv("books_scraped.csv", index=False)
Your notebook uses range(1, 51) for the 50 catalogue pages. For an exam asking for at least 20 books, stop after 20 records or scrape one or more pages and keep the first 20.

C. OYO website — headers and optional fields

Use when: the question asks to extract hotel listings from a page whose HTML is returned by a request. Your notebook sets browser-like request headers, parses the page with BeautifulSoup and finds hotel cards using a CSS class.

Fields extracted in your notebook: hotel name, star rating, review-count/summary text, image URL, displayed price and address.

OYO extraction template — based on your notebook selectors

PYTHON · OYO HOTEL LISTINGS
import requests
import pandas as pd
from bs4 import BeautifulSoup

url = "PASTE_THE_PROVIDED_OYO_SEARCH_URL"

headers = {
    "User-Agent": "Mozilla/5.0",
    "Accept": "text/html,application/xhtml+xml",
    "Accept-Language": "en-US,en;q=0.9"
}

response = requests.get(url, headers=headers, timeout=25)
response.raise_for_status()

soup = BeautifulSoup(response.text, "lxml")

hotels = soup.find_all(
    "div",
    class_="oyo-cell--12-col oyo-cell--8-col-tablet oyo-cell--4-col-phone"
)

hotel_list = []

for hotel in hotels:
    name_tag = hotel.find(
        "h3",
        class_="listingHotelDescription__hotelName d-textEllipsis"
    )
    rating_tag = hotel.find(
        "span",
        class_="is-fontBold hotelRating__rating hotelRating__rating--verygood hotelRating__rating--clickable"
    )
    review_tag = hotel.find(
        "span",
        class_="hotelRating__ratingSummary hotelRating__rating--clickable"
    )
    address_tag = hotel.find("span", class_="u-line--clamp-2")
    price_tag = hotel.find(
        "span",
        class_="listingPrice__finalPrice listingPrice__finalPrice--black"
    )
    image_tag = hotel.find("div", class_="c-ahj8kj")

    hotel_list.append({
        "name": name_tag.get("title") if name_tag else None,
        "star_rating": rating_tag.get_text(strip=True) if rating_tag else None,
        "num_rating": review_tag.get_text(strip=True) if review_tag else None,
        "image": image_tag.img.get("src") if image_tag and image_tag.img else None,
        "price": price_tag.get_text(strip=True) if price_tag else None,
        "Address": address_tag.get("title") if address_tag else None
    })

df = pd.DataFrame(hotel_list)
print("Hotels found:", len(df))
print(df.head())

df.to_csv("oyo.csv", index=False)
Your notebook first tries direct extraction, then uses try/except for each field so one missing field does not stop the whole loop. The template above uses the same idea with checks such as if price_tag else None.
OYO pages may render listing data dynamically or change their HTML class names. If len(hotels) is 0, inspect the response HTML and confirm the data is present in the returned page. A browser User-Agent header does not guarantee that the server will return the same content as a browser. Follow the site's terms and access rules.

E. API vs website scraping — quick decision

If the question gives…Use…Extract from…
API endpoint + API keyrequests.get() + response.json()JSON keys / list, often data["results"]
Website URL with HTML elementsrequests.get() + BeautifulSoup()HTML tags, classes and attributes
Several result pagesLoop + append to listAPI page parameter or website pagination URL
Common workflow for all three notebooks: imports → request → parse response → extract records into a list → DataFrame → head() → to_csv(). The parsing step is what changes between API JSON and website HTML.
